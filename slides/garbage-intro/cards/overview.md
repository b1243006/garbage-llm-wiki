# 證據卡：總覽：垃圾大致分成四類

只來自 `wiki/concepts/overview.md`，照原文抄，沒有改寫。

- 一般垃圾：資料明寫要丟一般垃圾的東西，例如吸管、杯口封膜、用過的衛生紙、感熱紙、沾到湯汁油漬的塑膠袋。[doc_01][doc_03][doc_06]
- 資源回收：紙箱、報紙等紙類，以及紙容器、鋁箔包、塑膠容器、保麗龍、鐵鋁罐、玻璃容器可以回收，各有回收前要做的處理。[doc_03][doc_02][doc_04][doc_05][doc_07][doc_08][doc_09]
- 資源回收裡有幾樣要特別處理：高壓罐要排空殘氣並單獨包裝，電池不可以丟一般垃圾，燈管用紙套包好，水銀體溫計用原包裝盒打包，廢食用油放涼後裝瓶。[doc_08][doc_10][doc_11][doc_13]
- 廚餘：剩菜剩飯等，要先瀝乾並挑掉雜物。[doc_12]
- 巨大垃圾：家具、床墊要先聯絡所在地環保局、清潔隊或受委託的清運單位，約好時間和地點再排出。[doc_16]
- 垃圾分類有全國共通的原則，但細節各地不一樣。[doc_18]
